# Reproduction for a React-Spectrum/Firefox Interop Issue

This is a "minimal" reproducing example for https://github.com/adobe/react-spectrum/issues/9122
in a nextjs setting. It's about as minimal as anything generated by `npx create-next-app` has a
chance of being.

# Steps to reproduce

Run

    npm ci
    npm run cypress:open

Choose component testing in Firefox, run the `pageHome.cy.tsx` tests. Cypress will manage to
click the plain button fine but report `NotFoundError: Element.releasePointerCapture: Invalid pointer id`
when clicking the React-Spectrum button.

# Where to look at the code

The two files worth looking at are

- `app/page.tsx` puts a plain and a spectrum button onto the main page
- `app/pageHome.cy.tsx` contains the cypress test that reproduces the issue

Apart from that, the only thing here that's not generated by either NextJS or Cypress is `app/provider.tsx`,
which is lifted whole cloth from https://react-spectrum.adobe.com/react-spectrum/routing.html.
