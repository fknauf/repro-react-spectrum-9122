# Reproduction for a Cypress/React Discrepancy

This is a "minimal" reproducing example to demonstrate the different order of mouse/pointer over/enter
events. It's about as minimal as anything generated by `npx create-next-app` has a chance of being.

# Steps to reproduce

Run

    npm ci
    npm run dev

Open Firefox or Chrome, navigate to http://localhost:3000, open the developer console, and click the
button. The developer console will show the PointerEnter/MouseEnter events before the corresponding
PointerOver/MouseOver. Next run

    npm run cypress:open

Choose component testing in Firefox or Chrome, open the developer console, and run the `pageHome.cy.tsx`
tests. Cypress will log the PointerOver/MouseOver events before the corresponding PointerEnter/MouseEnter.

# Where to look at the code

The two files worth looking at are

- `app/page.tsx` puts a plain and a spectrum button onto the main page
- `app/pageHome.cy.tsx` contains the cypress test that reproduces the issue

Apart from that, the only thing here that's not generated by either NextJS or Cypress.
